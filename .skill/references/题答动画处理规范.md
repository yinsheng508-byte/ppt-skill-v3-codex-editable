# 题答动画处理规范

仅在页面含提问、练习、病例讨论、观察提示或答案揭示时加载。完整块和执行流程沿用[PPT动画轻量规范](PPT动画轻量规范.md)，本页负责区分题答关系和防止提前露答。

## 1. 先确认题目要观众做什么

问号不是唯一依据。“如何提高效率”可能是章节题目，开放观察也可能没有唯一正确答案。先读题干、条件、选项、邻近说明和页底结论，区分下面内容；不补写、推导或纠正用户答案。

| 语义内容 | 判断依据 | 默认展示 |
|---|---|---|
| 题干、已知条件、普通选项 | 理解和作答所需的材料 | S0先见并保留 |
| 标准答案 | 原稿明确给出的结果、正确选项、判断或结论 | 新人工点击出现 |
| 观察提示 | 帮助观察或思考的方向，没有完整标准答案 | 按需要点击揭示，回报称“提示” |
| 解析/依据 | 解释答案原因或推导过程 | 当前安排在对应答案后的另一次点击 |
| 开放讨论归纳 | 对交流或观察的总结，不一定唯一 | 有原稿内容时讨论后点击，无原稿不新增 |

病例资料、作品、数据图等必要材料通常先见；材料里直接写出的诊断、结果、答案标记另作判断。必要提醒始终显示，不能为隐藏答案同时遮住必须保留的信息。

## 2. 当前可执行模式与限制

| 模式 | S0 | 点击安排 | 当前能力 |
|---|---|---|---|
| 单题与解析 | 题干、条件、选项 | 1答案+标记；2独立解析 | 支持，无解析不增加该步 |
| 一页多题 | 所有题干及对应条件/普通选项 | 各题答案使用不同点击；解析在对应答案后 | 支持，默认按题号/阅读顺序 |
| 开放观察与提示 | 问题、观察材料 | 对应提示等待点击，如有总结再另一步 | 支持，不把提示称标准答案 |
| 同题多对象答案 | 题干、材料 | 答案文字、专属底板、正确标记同次出现 | 支持，同题多个answer单元必须同序号 |
| 逐题推进 | 题1 | 答1→题2→答2 | 当前不支持题干后续进入，不能改role绕过 |
| 同题多级提示后出答案、答案分步推导 | 题干 | 提示1→提示2→答案… | 当前单题一个答案/提示揭示节点不支持此独立编排 |

用户未指定时用支持的默认模式，不为选模式新增问题。明确要求未支持模式时说明限制，处理其余支持页；不悄悄替换其明确要求或修改原对象。当前只有累计显示，不承诺点击切换题目、隐藏上一题或退页自动重置。

## 3. 逐处排除提前露答

按顺序检查一次，只对可疑局部细看，不给正常题目增加额外全稿审计。

1. **正文题答：** 答案、提示、独立解析是否在后续步骤？题干和条件是否完整先见？
2. **标记与样式：** 勾、星号、正误标签、选中框、独立高亮对象是否给出了结果？普通选项文字与正确标记分开归属。
3. **其他文本：** 标题、旁注、图例、页底总结是否直接透露答案？独立答案对象可归入答案步；题答混在同一对象时不能拆改。
4. **图像与背景：** 是否含答案文字/正确标记？看当前源的相关图像或可信预览。用于推理的证据不等于直接露答，不把全部图表当答案隐藏。
5. **整体复核：** 隐藏答案正文后，其他题答案、残留标记、总结是否仍泄露本题？问题与对应揭示单元是否配对正确？

正确标记已做在普通选项同一文本对象样式内，或答案烘焙在背景/图片里，隐藏整个对象将使题目材料不完整时，标记该页需要分层。题答同框、混合父组同理：不拆框、解组、改色、重绘或盖遮罩；不能将整题隐藏或答案全显当作完成。

图片/组内容不清时，不因XML没检出文字就判定无答案。无法核实该页就报告“图内答案未能核实”，不填虚假的视觉通过。

## 4. 语义如何映射为当前plan

先确定语义和短计划，再绑定完整对象清单；一个顶层ID只归属一次，不能为了过校验倒改角色。

| role | 使用规则 |
|---|---|
| `question` | 真实题干，必填question_id，当前click=0；题干碎片可分单元但同题号 |
| `given` / `options` | 对应题号的条件/普通选项，当前click=0 |
| `answer` | 原稿答案的完整揭示块，click>0、同题号；同题所有answer同次出现 |
| `answer_marker` | 对应答案的独立正确标记，与answer同题号、同click |
| `explanation` | 原稿独立解析，与answer同题号且click严格更大 |
| `content` | 普通内容、共享背景/标题等，不是漏判题答的兜底角色 |
| `decoration` / `safety` | 公共装饰/必要提醒，当前click=0 |

局部底板、编号和装饰属于内容块时，直接列入该块targets，不拆成必须静态的decoration。共享背景不重复列入多个题的targets。question_id反映真实对应关系，不能把同题不同答案步骤伪装成多题。

当前没有hint角色：**开放观察只有一个提示揭示节点时**，可用answer作为执行层“等待点击揭示”的锚点；unit.id写“Q1观察提示”，短计划和回报仍称提示。这不是新增标准答案；有真实答案又需分步提示的情况遵守上述能力限制。

含图片/组合图形的题答页，实际核对相关源图后才填 `visual_checked:true`。在任务备注按页记录真实源图part/路径或可定位预览与结论，不填虚构文件名。布尔值只记录主控看过，不证明语义正确，更不代表播放通过。

`needs_layering:true`会拒绝该页apply；把原因放任务备注，将该页从执行pages排除并回报未处理。不能改成false或把答案改静态来消除错误。

## 5. 最小复核与回报

执行前对照原文和必要图像，默读一次S0→点击1→点击2：题干保留、题号正确、答案全成员同步、其他题无提前露答。不能只看plan中自行填写的role；将静态组与原文再次对应。

例：三道开放观察题，S0三个问题与材料；点击1/2/3出各自提示；总结如需等待讨论则点击4。无总结就没有第4步，不需要停顿的总结不机械新增点击。

文件检查证明目标/时间树和内容保护，不证明上述语义判断。首屏、停留、逐点击、题干保留、退页/重放按软件与文件分别记录，没观察就标待验；普通调用不反复确认保存。回报区分“标准答案”“观察提示”和“未处理页”。
