# 风格模板使用规范

本文只规定风格模板如何触发、读取、注册和维护。模板可以帮助主控提出初步风格方向，但不替代阶段1规划、阶段2封面候选、用户确认或主控审美判断。

## 定位

风格模板用于：

- 阶段1提出初步风格方向。
- 阶段1写入项目 `图片风格.md` 和必要的 `PPT一致性.md` 规则。
- 阶段2A生成四张封面候选时提供可选风格语料。
- 用户选择封面后，辅助主控沉淀 `deck_style.json` 和 `layout_intent.json`。

风格模板不是正式项目产物，不是自动套用的死模板，也不能直接复制到阶段目录冒充项目规划。具体规则仍以项目 `PPT一致性.md`、`图片风格.md`、批准正文和用户最新反馈为准。

## 存放位置

模板目录：

```text
assets/templates/风格模板/
```

注册表：

```text
assets/templates/风格模板/registry.json
```

新增模板时，先复制 `assets/templates/风格模板/模板骨架.md`，再把正式模板文件注册到 `registry.json`。

## 使用时机

- 用户输入风格模板快捷指令时，先从 `registry.json` 解析对应模板。例如 `/医学PPT` 对应 `assets/templates/风格模板/医学PPT.md`。
- 用户明确指定某类风格模板时，主控读取对应模板。
- 普通 PPT 项目不默认读取所有模板。
- 模板只提供参考语料，主控必须筛选后回填项目 `图片风格.md`、`PPT一致性.md` 或逐页规划，再进入 `image_prompt_plan`。

## 使用边界

- 快捷指令只确定风格上下文，不代表用户已确认阶段1规划、封面风格、图片版 PDF、阶段3逐字稿/教案或阶段4整理交付。
- 不能跳过阶段2A四封面候选，除非用户明确要求主控直接代选。
- 不能因为模板存在，就让 runtime 自动选择风格或推进阶段。
- 不能让模板压过用户的最新要求；用户口径优先于模板默认值。
- 不能把模板里的示例文字当成真实医学事实、真实报告数据、用户单位、时间或讲者信息。
- 不能把模板整段追加到 final prompt；final prompt 的编译规则见 [提示词建设规范.md](提示词建设规范.md)。
- 页码、标题区、logo、模块页和公共元素规则以 [PPT一致性文档规范.md](PPT一致性文档规范.md) 为准；模板只给候选建议。
- 图片风格来源、参考图解释、风格返工和用户提示词交付边界以 [图片风格与提示词交付规范.md](图片风格与提示词交付规范.md) 为准。

## 注册表字段

每个模板记录至少包含：

- `id`：机器可读英文 ID，只用小写字母、数字和连字符。
- `name`：中文名称。
- `status`：`active`、`draft` 或 `deprecated`。
- `template_path`：模板 Markdown 相对路径，必须位于 `assets/templates/风格模板/`。
- `triggers`：快捷指令列表，例如 `["/医学PPT"]`。
- `description`：一句话说明模板用途。
- `usage_policy`：声明是否遵守阶段流程、是否跳过用户确认、是否默认页码。

`usage_policy.skip_user_confirmations` 必须为 `false`。风格模板不能越过 PPT Skill v3 的用户确认点。

`usage_policy.page_number_default` 必须为 `false`。所有风格模板默认不加可见页码，只有用户明确要求时才启用。

## 维护流程

新增一个风格模板时：

1. 复制 `assets/templates/风格模板/模板骨架.md`，命名为新的中文模板文件。
2. 写清适用场景、受众、视觉关键词、禁用风格、页面类型建议、封面候选建议和质量检查。
3. 在 `assets/templates/风格模板/registry.json` 增加记录，设置 `id`、`triggers`、`template_path` 和 `usage_policy`。
4. 运行 `python3 .skill/scripts/pptctl.py validate-style-templates`。
5. 运行 Skill 校验：`python3 /Users/yinxinhe/.codex/skills/.system/skill-creator/scripts/quick_validate.py .skill`。

查看和解析模板：

```bash
python3 .skill/scripts/pptctl.py list-style-templates
python3 .skill/scripts/pptctl.py resolve-style-template --query /医学PPT
python3 .skill/scripts/pptctl.py validate-style-templates
```

## 模板应包含

- 适用场景和受众。
- 用户口径和资料边界。
- 视觉关键词和禁用风格。
- 色彩、字体、标题区、公共元素和页面类型建议。
- 内容密度、留白、信息层级和不可过度精简的知识点。
- 阶段2封面候选的差异化建议。
- `deck_style.json` 和 `layout_intent.json` 的可参考片段。

模板内容应避免空泛词，例如只写“高级”“好看”“科技感”。每条要求尽量落到颜色、位置、字号、留白、构图、图表、插画、信息密度或禁用项。
