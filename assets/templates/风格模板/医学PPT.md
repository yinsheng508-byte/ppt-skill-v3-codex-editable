# 医学PPT风格模板

快速调用：`/医学PPT`

## 模板定位

医学 PPT 默认走专业、权威、克制、清晰的蓝白视觉路线。适用于疾病科普、临床培训、指南解读、病例复盘、学术汇报、护理宣教和医院内部培训。

这个模板的核心不是“做得很炫”，而是让医学知识点、数据、诊疗逻辑和风险提示被清楚看见。

## 用户口径

- 整体专业、权威，不做可爱插画风、潮流插画风或过度营销风。
- 内容保持专业和丰富，不能为了视觉简洁过度删减知识点。
- 版式简洁、干净、稳定，避免复杂、凌乱、过度装饰的排版。
- 默认不设置可见页码；只有用户明确要求加页码时才启用。
- 左上角小标题保持简单，便于整套统一。
- 每页顶部小标题必须使用同一标题区样式和同一 prompt 片段，只替换本页标题，避免位置、字号、装饰漂移。
- 每个模块介绍页必须使用同一结构和同一 prompt 片段，只替换模块编号、模块标题和必要短说明。
- 页面需要有呼吸感，不能把内容堆得密密麻麻。
- 色彩偏蓝色专业路线。
- 中文字体使用 `Microsoft YaHei`。
- 封面必须清楚呈现医院/机构、汇报人、汇报时间等基础信息；资料未提供时，阶段1应向用户补齐或在规划中明确预留字段，不能编造。
- 只对需要讲清知识的页面做文字增强，不是所有页面都加厚；主控大模型要按页面角色判断，医学知识讲解页不能过度精简成口号或情绪化短句，定义、流行病学、风险因素、分级/评分、诊断流程、鉴别诊断、防治策略等关键讲解内容应尽量保留。
- 插画式背景只能做辅助介绍，不承载密集文字、微型标注或装饰性伪标签；所有可见文字必须清晰、可读、无乱码。
- 目录页简洁、干净、清晰，以一、二、三、四要点为主，不加大量插画。

## 视觉关键词

推荐关键词：

- 专业医学
- 蓝白秩序
- 临床权威
- 信息清晰
- 证据导向
- 稳定页眉
- 轻量图表
- 克制强调

避免关键词：

- 卡通
- 可爱
- 儿童插画
- 多彩渐变
- 霓虹科技
- 复杂拼贴
- 高饱和撞色
- 过度 3D
- 大量装饰图标

## 色彩系统

主色建议：

- 深医学蓝：`#083B7A`，用于封面主标题、一级标题、关键数字。
- 标准专业蓝：`#2563EB`，用于页眉标题、强调线、重点标签。
- 浅蓝底：`#EFF6FF`，用于轻背景、模块底色、表格分区。
- 医疗青绿：`#0EA5A8`，少量用于数据下划线、风险提示点或第二强调色。
- 正文深灰：`#1F2937`。
- 辅助灰：`#64748B`。
- 边框浅灰蓝：`#D8E3F5`。
- 页面背景：`#F7FAFF` 或纯白。

使用规则：

- 每页主视觉颜色以蓝白灰为主，青绿只做少量辅助强调。
- 单页强调色不超过 2 个。
- 不使用大面积红色、橙色、紫色、粉色或高饱和多色块。
- 红色只用于严重风险、禁忌、警示，不做普通装饰。
- 渐变可以少量使用在强调条或医学影像区域，但必须轻、干净、低复杂度。

## 字体系统

统一使用：

```text
Microsoft YaHei
```

建议层级：

- 封面主标题：48-64 pt，深医学蓝，加粗。
- 封面副标题：22-30 pt，辅助灰或深蓝 80%。
- 内页左上标题：22-30 pt，标准专业蓝或深医学蓝，加粗。
- 正文：16-22 pt，深灰。
- 表格文字：13-18 pt，保证可读，不小于 12 pt。
- 脚注和来源：8-11 pt，辅助灰。

禁用：

- 不使用 `PingFang SC` 作为执行字体或 fallback。
- 不使用书法体、手写体、圆润儿童字体。
- 不为了塞内容把正文压到不可读字号。

## 固定视觉家具

页眉：

- 左上角放简单页面标题或章节标题，普通内页全套固定同一标题区位置、字号、颜色、字重、对齐方式和分隔线。
- 标题左侧可放小型医院 logo 或简洁医学图标，但没有用户素材时不要伪造 logo。
- 标题下方使用一条细蓝线贯穿到右侧，线宽克制。
- 右上角可使用三个小蓝点作为轻量装饰，但必须全套统一；也可以完全不使用。
- 不让标题一页居中、一页靠左、一页变成徽章、一页变成大海报标题。

页码：

- 默认不显示可见页码。
- 只有用户明确要求加页码时才启用；启用后必须全套位置和样式统一。

logo：

- 用户提供正式 logo 时，统一放左上角，尺寸小，不抢标题。
- 用户未提供 logo 时，不生成虚构 logo，不使用复杂徽章。

背景：

- 以纯白或极浅蓝白为主。
- 可以有非常淡的医学纹理、网格、波形或器械/器官轮廓，但只能低透明度、局部出现。
- 背景不能影响文字阅读。

## 内容密度

医学 PPT 需要保留专业信息，但要建立层级：

- 一页只承担一个核心讲解目标。
- 复杂知识点优先拆成标题、结论句、分组卡片、表格、流程或数据模块。
- 正文段落尽量短句化，每个模块 2-5 行为宜。
- 当资料很多时，优先使用两栏、三栏、表格、时间轴、流程图，而不是长段落堆叠。
- 每页四周保持稳定留白，重要模块之间留出明确间距。
- 表格页可以信息丰富，但必须有表头、分区、行间浅底色或分隔线辅助阅读。

## 知识讲解保留规则

医学 PPT 经常承担课件和专业讲解任务，但文字增强必须是页面级、选择性的。主控大模型要先判断每页是不是承担知识讲解任务；只有需要讲清医学概念、证据、流程或策略的页面，才保留较厚讲解文字。封面、目录、章节过渡、纯结论页和视觉强调页仍应保持简洁。

优先保留：

- 定义、概念边界和适用范围。
- 流行病学、发生率、患病率和临床意义。
- 危险因素、易患人群和高危场景。
- 分级、评分或风险评估工具，例如 OSTA、T 值、FRAX 等。
- 诊断流程、鉴别诊断和检查依据。
- 治疗原则、防治策略、随访管理和患者宣教要点。
- 指南、研究、数据来源和重要限定条件。

压缩方式：

- 可以删掉重复铺垫、情绪化修辞和不影响理解的连接句。
- 不删核心医学概念、数字、阈值、分级名称、诊断步骤和防治策略。
- 如果知识讲解页信息过多，优先拆成连续两页、表格、流程图或分组卡片，不直接砍掉知识模块。
- 阶段1规划时要先判断页面是“封面/目录/过渡/总结/视觉强调页”还是“医学知识讲解课件页”；只有后者需要文字增强，其他页面继续保持简洁清晰。

## 常见页面版式

### 封面

推荐：

- 大标题左上或居中偏左，深医学蓝。
- 副标题放在标题下方，灰蓝色。
- 标题区之外设置一组克制的封面信息栏，清楚写出医院/机构、科室或项目组、汇报人、汇报时间；信息栏可放左下、右下或标题下方，字号低于副标题但必须可读。
- 如果用户没有提供医院、汇报人或时间，封面候选和阶段1规划都应保留明确字段，例如“医院：待补充”“汇报人：待补充”“时间：待补充”，不生成虚构名称。
- 主视觉可以是克制的医学场景、器官示意、临床设备、抽象医学线条或数据背景。
- 背景留白充足，不加大量图标。

不推荐：

- 大面积人物插画。
- 花哨渐变和强光效。
- 标题压在复杂图片上导致可读性下降。
- 只写大标题而缺少医院、汇报人、时间等汇报基础信息。

### 目录页

推荐：

- 标题为“目录”或项目指定名称。
- 使用 01 / 02 / 03 / 04 或 一 / 二 / 三 / 四 的清晰编号。
- 每个目录项包含短标题，可加一行很短说明。
- 结构可以是纵向列表、两列列表或四象限清单。
- 不加大型插画；最多使用细线、浅蓝块或编号圆点。

不推荐：

- 目录项塞入大段解释。
- 使用多种图标和插画填满页面。
- 做成复杂流程图。

### 模块介绍页

推荐：

- 所有模块介绍页使用同一画面骨架，只替换模块编号、模块标题和必要短说明。
- 编号容器、标题位置、分隔线、医生或医学主视觉位置、背景波形和装饰图标保持一致。
- 标题大而清楚，背景蓝白留白，插画只做辅助。
- 模块页之间可以通过编号和标题区分，不通过随机换版式区分。

不推荐：

- 一页用圆形编号，一页用方形编号，一页无编号。
- 一页标题居中，一页标题靠左，一页标题靠右。
- 医生人物、波浪背景和装饰图标每页随机变化。

### 数据页

参考方向：

- 可以使用大数字、三栏指标、细分隔线、少量青绿色短线强调。
- 数据来源放底部脚注，字号小但可读。
- 关键数字用深医学蓝，解释文字用深灰。

适用场景：

- 患病率、治疗率、控制率、风险比例、指南推荐级别、样本量、研究结果。

### 知识讲解页

推荐：

- 页面标题明确写出本页讲解对象，例如“危险因素”“诊断流程”“防治策略”。
- 使用一条结论句建立阅读方向，再用 2-4 个模块展开知识点。
- 对评分工具、诊断标准、分级标准等内容，优先使用表格或步骤结构完整呈现。
- 对“定义 + 流行病学 + 风险因素 + 诊断/鉴别 + 防治策略”这类体系化内容，可以拆成多页连续讲解，保持知识链条完整。
- 文字增强只发生在这类知识讲解页；目录、过渡页、总结页不因为使用医学模板而自动加厚。

不推荐：

- 把知识页压缩成只有一句观点或三四个宽泛词。
- 为了留白删除关键概念、风险分层、诊断步骤或防治策略。
- 只保留视觉标签，不保留必要解释文字。

### 机制讲解页

推荐：

- 左侧或上方给出一句机制总述。
- 下方用 3-4 个卡片解释不同机制。
- 每张卡片只用一个简洁医学图标或无图标。
- 重点词加粗或用蓝色强调。

适用场景：

- 病理生理、危险因素、药物作用机制、手术原理、并发症机制。

### 表格页

推荐：

- 用浅蓝表头、浅灰蓝行底、细分隔线。
- 高风险或重点列可以用蓝色竖向重点卡片突出。
- 表格文字保持克制，不使用过多颜色。

适用场景：

- 分级标准、风险因素、诊疗方案对比、指南条目、禁忌证和适应证。

### 流程页

推荐：

- 使用横向或纵向步骤流。
- 每一步使用短标题加 1-2 行说明。
- 箭头和节点使用统一蓝色。
- 适合保留判断节点，但不要做成复杂迷宫。

适用场景：

- 诊疗路径、筛查流程、急救步骤、围手术期管理、患者宣教流程。

### 总结页

推荐：

- 3-5 条核心结论。
- 每条结论可以用编号、短横线或浅蓝标签。
- 可以加“临床启示”“操作要点”“风险提示”等标题。

不推荐：

- 只写一句空泛口号。
- 再次堆大量正文。

## 图片和插画规则

- 医学示意图可以使用，但必须准确、干净、辅助理解。
- 插画优先线性、低饱和、局部小面积使用。
- 器官、血管、设备图应偏专业示意，不走可爱拟人风。
- 没有必要时，纯信息设计优先于插画。
- 插画式背景用于辅助介绍时，背景本身尽量无字；如确需标注，只允许少量、大字号、清晰中文标签。
- 不在插画背景、医学示意图、设备界面或纹理中生成密集文字、微型注释、英文占位、随机标签、伪文字或乱码。
- 需要讲解的正文、数字、术语和来源应放在干净的文本区、表格、卡片或流程节点中，不嵌入复杂插画细节里。
- 不使用复杂背景照片、暗色手术场景、夸张病灶渲染或恐吓式视觉。

## 阶段2封面候选建议

四张封面候选可以在同一医学蓝白系统下做明显差异：

- A 专业数据型：大标题 + 关键统计数字/曲线/研究证据背景，权威、理性。
- B 临床场景型：克制医学场景或器械背景 + 清晰标题，专业、可信。
- C 机制示意型：局部器官/血管/细胞机制示意 + 标题，适合知识讲解。
- D 极简指南型：大留白 + 深蓝标题 + 细线和编号元素，适合指南解读或学术汇报。

四张候选都不能变成卡通科普风，也不能只是换蓝色深浅。

## layout_intent 参考方向

- 画布：16:9。
- 页面边距：左右保持稳定安全边距，内页正文区域不贴边。
- 页眉：左上标题 + 细分隔线，全套固定一致，只替换标题文字。
- 模块介绍页：同一骨架重复使用，只替换模块编号、模块标题和必要短说明。
- 目录：编号列表或两列编号清单。
- 数据：大数字三栏、指标卡、轻表格。
- 专业说明：两栏讲解、卡片分组、流程节点。
- 图文关系：图为辅，文字和医学逻辑为主；插图只占局部，不抢夺阅读。

## Prompt 约束短句

写阶段2图片 prompt 时可以按需加入：


## 质量检查

生成后主控大模型检查：

- 是否保持蓝白专业医学气质。
- 封面是否清楚呈现医院/机构、汇报人、汇报时间，且没有编造未提供的信息。
- 是否由主控按页面角色选择性增强文字：医学知识讲解页保留定义、风险因素、评分/分级、诊断、鉴别和防治策略等必要内容；封面、目录、过渡、总结和视觉强调页没有被错误加厚。
- 插画式背景是否没有密集文字、微型注释、随机标签或伪文字；所有可见文字是否清晰可读、无乱码。
- 是否没有页码。
- 用户未明确要求时是否没有可见页码。
- 左上角标题是否简洁统一，没有位置、字号、装饰漂移。
- 每个模块介绍页是否使用同一结构和同一 prompt 片段，只替换模块文案。
- 正文是否专业、足够丰富且可读。
- 表格、卡片、流程是否清晰。
- 插画是否克制，没有抢内容。
- 单页是否仍有呼吸感。
- 目录页是否只突出清晰编号和要点。
