# 阶段1设计合同规范

## 目标

阶段1除了用户可见的 `页面规划.md`、`每页干净逐字稿.md` 和 `风格与提示词方案.md`，还必须由主控大模型写入机器态设计合同：

```text
_state/阶段1/design_contract.json
```

设计合同用于把路线、受众、资料边界、审美方向、页面角色和封面候选策略传递给阶段2。它不替代用户可见文档，也不由 runtime 自动生成正式内容。

## 与页面规划的关系

- `页面规划.md` 是阶段1权威逐页规划表。
- `每页干净逐字稿.md` 是阶段1用户阅读每页内容的干净审阅稿，必须从 `页面规划.md` 和 `content.json` 派生，不是另一套文字合同。
- `风格与提示词方案.md` 是阶段1用户可见的风格和图片提示词概要文档，合并承载初步风格方向、视觉系统、版式规则、全局提示词方向和逐页提示词概要。
- `content.json` 是 `页面规划.md` 的结构化镜像。
- `slide_prompt_briefs.json` 是阶段2 prompt brief。
- `design_contract.json` 是整套 PPT 的路线和视觉设计合同。

用户确认阶段1时，核心确认对象是：

```text
页面规划.md 的页数、页面角色、页面目的、每页最终可见中文文字、资料依据、内容保留边界
每页干净逐字稿.md 的逐页内容可读性和文字一致性
风格与提示词方案.md 的初步风格方向和图片提示词概要
```

## 资料整合要求

阶段1写 `页面规划.md` 前，必须整合阶段0资产：

```text
阶段0_资料整理/资料清单.md
阶段0_资料整理/资料摘要.md
_state/阶段0/materials_index.json
_state/阶段0/原始资料/
_state/阶段0/提取文本/
```

如果用户提供 PPT、Word、PDF、截图、表格、讲稿和聊天口径，主控大模型必须判断主材料和补充材料，处理重复、冲突和缺口。整合结论必须落到 `页面规划.md` 每页的 `资料依据` 和 `内容保留边界`，不要另建单独用户可见资料整合文档。

## 页面规划文字合同

`页面规划.md` 建议表格：

```markdown
| 页码 | 页面角色 | 页面标题 | 页面目的 | 最终可见中文文字 | 资料依据 | 内容保留边界 | 视觉意图 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 1 | cover | 高血压健康防护宣教 | 建立课程主题和行动承诺 | 高血压健康防护宣教；测得准 管得住 少并发；把血压管理变成每天做得到的小习惯 | 原PPT第1页 + 用户标题口径 | 不编造机构、讲者和来源 | 左侧标题层级，右侧护理测量场景 |
```

要求：

- “页码”是阶段规划索引，不代表阶段2/阶段3要在画面中添加可见页码；可见页码默认关闭，只有用户明确要求时才启用。
- “最终可见中文文字”必须逐条写清楚。
- “资料依据”必须能追溯到阶段0材料、原 PPT 页码、文档章节或用户口径。
- “内容保留边界”必须写清哪些文字、数字、术语、案例和结论不能删改。
- 仿做升级型默认 `preserve` 或 `soft_polish`，不能为了美观强压缩。

## 每页干净逐字稿

`阶段1_规划确认/每页干净逐字稿.md` 必须让用户能舒服地逐页审内容，不用在宽表格里读长文本。

基本要求：

- 每页使用 `## 第 01 页｜页面标题` 作为页标题。
- 每页保留简短的 `页面角色` 和 `本页目的`，帮助用户判断内容任务。
- `页面可见文字` 必须使用贴近页面结构的 Markdown 排版：封面用标题层级，目录用编号列表，知识讲解用小标题和要点，流程页用步骤，表格页用 Markdown 表格，总结页用编号结论。
- 不把多条文字用长分号挤在一行里。
- 不放资料依据、prompt、视觉说明、JSON 字段、内部制作说明或来源链接清单；这些仍放 `页面规划.md` 或 `_state/`。
- 不新增 `页面规划.md` / `content.json` 之外的页面可见文字；如为了排版补小标题，必须先同步写回 `页面规划.md` 和 `content.json`。
- 如果某页有用户待补充信息，写成清晰占位，例如 `医院：待补充`，不要编造。

## 风格与提示词方案

`阶段1_规划确认/风格与提示词方案.md` 必须合并原先风格方向和图片提示词概要，不再拆成两个用户可见文件。

建议结构：

- `## 初步风格方向`：模板方向、受众气质、视觉关键词、禁用风格。
- `## 视觉系统草案`：主色、辅助色、字体、标题区、模块介绍页、页码策略、logo/机构信息策略。
- `## 内容密度与版式规则`：不同页面角色的密度、表格/流程/图文关系、统一页眉和模块页规则。
- `## 全局提示词方向`：阶段2图片生成需要继承的全局风格和禁止项。
- `## 逐页提示词概要`：按页列出页面标题和视觉概要，不写正式 final prompt。
- `## 阶段2封面候选方向`：四张封面候选的大致差异。

要求：

- 保留会影响阶段2生成的风格、构图、文字密度、提示词和禁止项信息。
- 可以精简重复的颜色、字体、禁止项和风格描述。
- 不把正式 final prompt、packet、hash、provider JSON 或执行日志放进阶段目录。
- 不让 `风格与提示词方案.md` 修改 `页面规划.md` 已确认的每页文字。

## 禁止事项

- 不把 `design_contract.json` 放入用户可见阶段目录。
- 不让 `每页干净逐字稿.md` 成为第二套事实来源或绕过 `页面规划.md` 修改内容。
- 不再新建独立的 `风格方向.md` 或 `图片提示词概要.md` 作为阶段1正式用户可见产物；历史项目如已有这两个文件，应合并为 `风格与提示词方案.md`。
- 不用设计合同改变用户已确认的每页内容。
- 不让 runtime 自动写正式设计判断。
- 不让阶段2 prompt 使用 `页面规划.md` 之外的新文字。
