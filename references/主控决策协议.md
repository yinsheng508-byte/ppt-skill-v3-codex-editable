# 主控决策协议

本文件定义 decision 类型、记录格式和执行边界；用户确认红线和主控/runtime 职责边界以 `核心不变量.md` 为准。

## 原则

阶段切换必须来自主控大模型的显式决策。不能因为文件存在、状态字段变化、脚本默认规则或 handoff 文件存在就自动进入下一阶段。

普通 decision 优先使用 `python3 scripts/pptctl.py make-decision --run-dir <项目目录> --type <decision_type> --notes <说明>` 生成并记录；需要用户确认的 decision 必须显式传 `--user-confirmed`。`record-decision` 继续兼容主控手写完整 JSON 的特殊场景。

决策文件放在：

```text
outputs/projects/<中文项目名>/_decisions/
```

## 决策类型

```text
stage1_ready_for_user_review
approve_stage1_start_stage2
request_stage1_revision
stage2_cover_options_ready_for_user_review
approve_stage2_cover_style_start_image_deck
request_stage2_cover_style_revision
stage2_trial_first5_ready_for_user_review
approve_stage2_trial_first5_continue_remaining
request_stage2_trial_first5_revision
stage2_ready_for_user_review
approve_stage2_start_stage3
approve_stage2_skip_stage3_start_script_output
request_stage2_revision
reopen_stage3_sample_after_stage4
approve_stage3_coordinate_plan_start_text_fill
request_stage3_coordinate_plan_revision
stage3_ready_for_user_review
approve_stage3_start_script_output
request_stage3_revision
stage4_script_completed
```

## 执行规则

- Runtime 只能执行 `execution.allowed_actions` 明确列出的动作。
- 阶段2/阶段3生图路线不新增 decision 类型；在 `execution.image_generation_route` 或 `basis.image_generation_route` 中记录 `codex_image_gen`（默认）或 `openai_image_api`。没有显式记录时，主控默认按 `codex_image_gen` 执行。
- `user_confirmed=false` 时不能执行用户确认后的阶段切换。
- `controller_reviewed=false` 时不能进入下一阶段。
- 返工 decision 只能把流程退回指定阶段，不能顺便自动重跑后续阶段。
- 决策文件是放行记录，不是用户可见交付物。
- `approve_stage1_start_stage2` 只打开阶段2A封面候选，不直接生成全套整页图片。
- `approve_stage2_cover_style_start_image_deck` 必须基于用户选择的封面风格，并要求 `deck_style.json` 和 `layout_intent.json` 已写入；选中封面候选无明显质量问题时，下一步应执行 `promote_selected_cover_option`，将其转正为正式封面页，不重复生成封面。
- `stage2_trial_first5_ready_for_user_review` 指阶段2B试样已准备好，让用户确认视觉、文字、密度和风格方向；命名沿用历史 first5，默认试样为3页确认范围，已转正封面只列入说明、不再生图。
- `approve_stage2_trial_first5_continue_remaining` 只表示试样方向通过，可以 promotion 已通过试样并继续生成剩余页面；已由封面候选转正的页面保持原正式结果，不再 promotion，不表示阶段2图片版 PDF 已确认。
- `request_stage2_trial_first5_revision` 表示试样需要返工，默认返工 `deck_style.json`、`layout_intent.json` 或阶段2 prompt，不修改阶段1内容资产。
- `stage2_ready_for_user_review` 指图片版 PDF 已准备好，不指封面候选已准备好。
- `approve_stage2_skip_stage3_start_script_output` 指用户确认阶段2图片版 PDF 可作为阶段4锁定稿，并明确跳过 Skill 阶段3；它只放行讲稿输出，不表示阶段3可编辑 PPT 已完成。
- `approve_stage3_coordinate_plan_start_text_fill` 指用户已确认阶段3文字坐标复刻，可以开始构建 handoff brief 并运行 OfficeCLI 坐标填字；它不等同于确认阶段3可编辑 PPT。
- `request_stage3_coordinate_plan_revision` 指用户认为阶段3文字坐标需要返工，主控必须回到阶段2确认图重新识别/标注坐标，不能继续填字。
- `reopen_stage3_sample_after_stage4` 指已完成项目在用户明确要求下重新打开阶段3样稿，只放行指定页范围的拆字、归属、去字背景和坐标复刻预览；它不自动确认坐标，不自动填字，也不改变已完成的阶段4讲稿事实。
- `approve_stage3_start_script_output` 指用户已确认阶段3可编辑 PPT，可以进入阶段4演讲稿输出；它不是交付验收。
- `stage4_script_completed` 指演讲逐字稿、Word 和 PDF 已生成并由主控检查通过；该决策不需要用户最终确认。

## 生图路线执行动作

阶段2/阶段3可使用以下 route-aware 动作名。旧动作名可以作为兼容别名保留，但新决策优先写这些动作：

- `dispatch_stage2_cover_options`：派发阶段2A四封面候选 packet，默认 `codex_image_gen`，可显式 `openai_image_api`。
- `record_image_generation_results`：主控把官方 `image_gen` 输出或中转 API 输出逐张登记成正式 result。
- `run_image_api_batch`：只用于 `openai_image_api` 中转路线。
- `dispatch_stage2_trial_first5_packets`：派发阶段2B试样 packet。
- `dispatch_stage2_remaining_packets`：派发阶段2B剩余页面 packet。
- `dispatch_stage3_background_packets`：派发阶段3保真去字背景 packet。

官方 `codex_image_gen` 路线不能写 `run_image_api_batch`；中转 API 路线不能缺少 `run_image_api_batch` 或等价 API 执行证据。

## 阶段2A封面风格决策边界

封面风格通过后，主控必须先判断选中封面候选能否直接作为正式封面页。只要没有明显质量问题，应先执行转正动作，再进入阶段2B试样派发。

```json
{
  "decision_type": "approve_stage2_cover_style_start_image_deck",
  "from_stage": "stage2",
  "to_stage": "stage2",
  "user_confirmed": true,
  "basis": {
    "confirmed_files": [
      "_state/阶段2/cover_options/selection/selection.json",
      "_state/阶段2/deck_style.json",
      "_state/阶段2/layout_intent.json"
    ],
    "notes": "用户选择封面风格，主控确认选中封面候选无明显质量问题，可直接转正为正式封面页。"
  },
  "execution": {
    "allowed_actions": [
      "promote_selected_cover_option",
      "dispatch_stage2_trial_first5_packets"
    ]
  }
}
```

## 阶段3文字坐标确认边界

阶段3坐标确认是阶段3内部确认点，不新增正式大阶段。坐标必须基于阶段2用户确认过的图片精准识别/标注，文字内容仍只能来自阶段1内容资产。

坐标通过：

```json

  "from_stage": "stage3",
  "to_stage": "stage3",
  "user_confirmed": true,
  "controller_reviewed": true,
  "basis": {
    "confirmed_files": [
```

## 阶段4讲稿决策边界

进入阶段4有三类锁定稿来源：

1. 默认路线：用户确认阶段3可编辑 PPT 后进入阶段4。
2. 跳过阶段3路线：用户确认阶段2图片版 PDF 可作为讲稿锁定稿，并明确跳过 Skill 阶段3后进入阶段4。
3. 外部锁稿路线：用户确认外部 PPTX/PDF 可作为讲稿锁定稿后进入阶段4；外部稿只作为阶段4输入，不反写阶段3完成状态。

默认路线：

```json
{
  "decision_type": "approve_stage3_start_script_output",
  "from_stage": "stage3",
  "to_stage": "stage4",
  "user_confirmed": true,
  "controller_reviewed": true,
  "basis": {
    "confirmed_files": [
      "阶段3_可编辑PPT/ppt/<封面第一页主题>｜可编辑PPT.pptx",
      "_state/阶段3/render_review/stage3_visual_qa_review.json"
    ],
    "notes": "用户确认阶段3可编辑 PPT，主控可基于锁定稿生成演讲逐字稿、Word 和 PDF。"
  },
  "execution": {
    "allowed_actions": [
      "author_stage4_speaker_script",
      "render_stage4_script_docx_pdf"
    ]
  }
}
```

跳过阶段3路线：

```json
{
  "decision_type": "approve_stage2_skip_stage3_start_script_output",
  "from_stage": "stage2",
  "to_stage": "stage4",
  "user_confirmed": true,
  "controller_reviewed": true,
  "basis": {
    "confirmed_files": [
      "阶段2_图片版PPT/pdf/<封面第一页主题>｜图片版PPT.pdf"
    ],
    "locked_presentation_source": {
      "source_mode": "stage2_image_deck",
      "source_path": "阶段2_图片版PPT/pdf/<封面第一页主题>｜图片版PPT.pdf",
      "confirmation_basis": "用户确认阶段2图片版 PDF 作为讲稿锁定稿，并明确跳过 Skill 阶段3。"
    },
    "notes": "主控确认阶段1内容资产与阶段2图片版 PDF 足够支撑阶段4演讲逐字稿输出；本决策不生成或确认阶段3可编辑 PPT。"
  },
  "execution": {
    "allowed_actions": [
      "author_stage4_speaker_script",
      "render_stage4_script_docx_pdf"
    ]
  }
}
```

执行该决策时，runtime 会把锁定稿 `source_sha256` 写入 `project_state.stage4_locked_presentation_source`。主控撰写 `speaker_script.json` 时，`basis.locked_presentation_source` 必须带上同一份 `source_mode`、`source_path` 和 `source_sha256`，确保阶段4讲稿可追溯到用户确认的锁定稿。

阶段4完成：

```json
{
  "decision_type": "stage4_script_completed",
  "from_stage": "stage4",
  "to_stage": "stage4",
  "user_confirmed": false,
  "controller_reviewed": true,
  "basis": {
    "confirmed_files": [
      "阶段4_演讲稿输出/<封面第一页主题>｜逐字稿.md",
      "阶段4_演讲稿输出/docx/<封面第一页主题>｜逐字稿.docx",
      "阶段4_演讲稿输出/pdf/<封面第一页主题>｜逐字稿.pdf",
      "_state/阶段4/speaker_script_manifest.json"
    ],
    "notes": "主控确认讲稿逐页绑定 PPT、Word/PDF 可打开且版式清晰，项目完成。"
  },
  "execution": {
    "allowed_actions": []
  }
}
```
